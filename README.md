# ssp-corpus

Estimating the prevalence of the Sonority Sequencing Principle (SSP) across languages.

## Pre-requisites

* Install Python 3.12
* Install uv
* Download file `data.zip` from the [OSF repository](https://osf.io/yeqms/files/osfstorage) (https://osf.io/yeqms/files/osfstorage) and unzip into the project folder.


## Running the code

### Prere
```bash
uv sync
uv run main
```
